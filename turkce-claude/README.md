# Türkçe Claude Code

Claude Code'un cevaplarını Türkçe yapar. `~/.claude/settings.json` dosyasına `"language": "turkish"` ekler; mevcut ayarlarınızı korur ve önce yedek alır.

## Kullanım

**macOS / Linux**
```bash
bash kur.sh          # aç
bash kur.sh kaldir   # kapat
```

**Windows (PowerShell)**
```powershell
.\kur.ps1            # aç
.\kur.ps1 kaldir     # kapat
```

Ardından Claude Code'u yeniden başlatın.

## Sınırlama
Bu ayar Claude'un **cevap dilini** değiştirir. Programın kendi arayüz metinleri (menüler, sistem mesajları) İngilizce kalır; onları değiştirmek için resmi bir yol yoktur.
